이 폰을 쓰는 사람

대사와 조언이 이 사람 기준으로 나옵니다.

모델

키·아이 정보·메모·기록은 이 폰에만 저장됩니다. 앱 파일에는 들어가지 않습니다.
실행할 때 입력한 내용과 아이 정보는 이 폰에서 Anthropic(미국) 서버로 바로 전송되어 답변을 만드는 데 쓰입니다. 앱 제작자를 거치지 않습니다.

키 발급: platform.claude.com → Settings → API keys → Create key
1회 실행 비용은 Sonnet 5 기준 약 10~30원, Haiku 4.5 기준 약 5~15원입니다.

주의: Safari 창에서 저장한 키는 홈 화면 앱으로 넘어가지 않습니다. 반드시 홈 화면 아이콘으로 연 뒤 입력하십시오.
